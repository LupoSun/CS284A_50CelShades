Real-Time Animation Rendering with Procedural Motion

Abstract

Celluloid is a real-time rendering system inspired by the hand-drawn, cel-shaded aesthetic of classic animation. Traditional cel animation is characterized by flat color fills, bold outlines, and deliberate motion curves — a style that is costly to produce manually but can be approximated computationally using modern graphics techniques.

Our system combines non-photorealistic rendering (NPR) with procedural motion synthesis to generate expressive, stylized animations in real time. Key contributions include an adaptive silhouette-edge detection pass, a palette-quantized Phong shading model, and a procedural in-betweening system driven by physically informed spring dynamics.

Technical Approach

1. Cel-Shading Pipeline

We implement a multi-pass OpenGL rendering pipeline that discretizes the continuous Phong shading model into a small number of color bands, producing the characteristic "stepped" illumination of cel animation. A configurable ramp texture maps the Lambertian dot product to user-defined toon bands (typically 2–4 levels), allowing artistic control over light-dark transitions.

2. Silhouette & Edge Detection

Bold outlines are central to the cel aesthetic. We detect silhouette edges geometrically during the vertex shader pass by comparing each triangle's face normal with the view direction and expanding back-facing geometry slightly along its normal to create an outline "shell." An additional screen-space Sobel filter on the depth buffer captures inner creases and fine detail edges that the geometric pass misses.

Edge weight formula: 
  w = α · depth_edge + β · normal_edge
  outline_width = base_width × (1 + γ / depth)

α, β, γ are artist-tunable parameters; depth normalization keeps outlines consistent across object distances.

3. Procedural In-Betweening with Spring Dynamics

Classical animation relies on in-betweening — interpolating frames between key poses. We drive this interpolation with a second-order spring system, giving animators direct control over stiffness, damping, and over-shoot to produce squash-and-stretch effects automatically. The spring state is integrated with a semi-implicit Euler step at 60 Hz, keeping the simulation stable even under large time steps.

  • Stiffness k – how quickly the character snaps to a new pose.
  • Damping c – how much oscillation is suppressed.
  • Mass m – effective inertia of each bone chain.

4. Palette Quantization & Color Style Transfer

To enforce a hand-crafted color palette, we apply k-means quantization in CIELAB color space at a post-processing stage. Users specify a target palette (or sample one from a reference image), and each output pixel is mapped to its nearest palette entry using a GPU-accelerated nearest-neighbor lookup in a 3-D LUT.

Problems Encountered

  • Silhouette popping: The geometric outline shell caused visible discontinuities at mesh seams. We addressed this by welding vertices with identical positions before the expansion pass.
  • Spring instability at low frame rates: Large Δt values caused the semi-implicit integrator to diverge. We clamped Δt to 1/30 s and sub-stepped when necessary.
  • Palette banding artifacts: Hard k-means boundaries produced harsh color transitions. Adding a small dithering pass (ordered Bayer matrix) smoothed the result without sacrificing the stylized look.

Results

Our system achieves real-time performance (>60 fps) on a mid-range GPU (NVIDIA GTX 1070) for scenes with up to ~50 000 triangles and 10 animated characters simultaneously. Below are representative outputs produced by the Celluloid renderer.
